# दिमाग घुमाऊ (Dimag Ghumau)

An original Nepali trick-puzzle game for mobile, drawn on a school blackboard (कालोपाटी). It has 20 levels, and each one uses a different trick.

**Play:** open `index.html` in a phone browser. It is a single file. Progress and hint bulbs are saved in the browser.

| # | Puzzle | Trick |
|---|---|---|
| 1 | सबैभन्दा ठूलो जनावर | real-life size, not drawing size |
| 2 | थालमा कति मोमो? | drag the lid to reveal a hidden one |
| 3 | डाँका कहाँ लुक्यो? | tap the word in the question |
| 4 | दियो बाल्नुहोस् | drag the diyo to the lit one (matches are empty) |
| 5 | झण्डामा कति त्रिभुज? | Nepal's flag is two triangles |
| 6 | 6 लाई 9 बनाउनुहोस् | tap to rotate |
| 7 | कुखुराले अण्डा पार्ने | long-press |
| 8 | २ + २ × २ | order of operations |
| 9 | घाम लगाउनुहोस् | drag the clouds away |
| 10 | सगरमाथामा झण्डा | the far mountain looks smallest; read the labels |
| 11 | भकुण्डो ५ पटक | rapid taps against gravity |
| 12 | नेपाली महिना क्रम | sequence |
| 13 | हजुरबाको टोपी | it's on his head |
| 14 | ४ कुनामा बिरालो | riddle: answer 4 |
| 15 | बाँदरलाई केरा | tool first (stick), then feed |
| 16 | सबैभन्दा ठूलो संख्या | tap the level number in the header |
| 17 | अँध्यारो कोठामा बिरालो | flashlight follows your finger |
| 18 | पानी उमाल्नुहोस् | don't touch anything, just wait |
| 19 | कपास कि फलाम? | both are 1 kg, so they're equal |
| 20 | भाग्ने "जित" बटन | pin it, then tap |

Hints cost one bulb. You start with 3 bulbs and earn +1 for each new level you clear.
